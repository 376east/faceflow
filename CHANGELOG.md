# Changelog

## [0.1.0](https://github.com/376east/faceflow/releases/tag/v0.1.0)

- Added a local photographer workspace to create shoots, upload and index photos, and publish or pause guest galleries.
- Added selfie search within a published shoot. Guests can review matching faces and download individual JPEGs or a ZIP of selected photos. Downloaded images have no face outlines.
- Published a Windows x64 source ZIP with a hashed dependency lock and verified model downloads. GitHub Actions installed and launched the bundle with CPython 3.12.10. [Release verification](https://github.com/376east/faceflow/actions/runs/44824706063)
