# FaceFlow

[English](README.md) · **[Скачать ZIP с исходниками для Windows](https://github.com/376east/faceflow/releases/download/v0.1.0/FaceFlow-v0.1.0-source.zip)** · [Описание выпуска и контрольная сумма](https://github.com/376east/faceflow/releases/tag/v0.1.0)

FaceFlow помогает найти фотографии со съёмки по селфи. Фотограф управляет галереей, а участники проверяют и скачивают найденные кадры на том же компьютере с Windows. Интерфейс приложения на русском.

## Запуск

1. Установите [CPython 3.12.10 для Windows x64](https://www.python.org/downloads/release/python-31210/) и распакуйте ZIP в папку, куда можно записывать файлы.
2. Откройте PowerShell в этой папке и выполните команды из [INSTALL.md](INSTALL.md). Для установки зафиксированных зависимостей Python и скачивания моделей распознавания нужен интернет. Команды проверяют зависимости и модели перед запуском.
3. Воспользуйтесь приватной ссылкой фотографа, которую FaceFlow откроет в браузере или выведет в PowerShell. По умолчанию приложение слушает `127.0.0.1:8765`, поэтому обе страницы галереи доступны только на компьютере, где запущен FaceFlow.

## Первый поиск

1. Создайте съёмку и загрузите фото, которые вы вправе обрабатывать. Дождитесь окончания обработки и нажмите **Опубликовать**.
2. В блоке **Ссылка для гостей** нажмите **Открыть**.
3. Добавьте селфи с одним видимым лицом, отметьте согласие на обработку и нажмите **Найти мои фото**. Проверьте найденные кадры и скачайте нужные.
