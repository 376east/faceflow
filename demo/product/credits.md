# Источники изображений FaceFlow

Демка использует реальные фото Wikimania 2019. Полные общие кадры сохраняют композицию. Для галереи часть файлов взята как 1600-pixel версия Commons, десять сложных кадров загружены в исходном разрешении. Многокадровый MPO экспортирован в один стандартный JPEG. Четыре фото лица вырезаны из отдельных снимков, исключённых из галереи. Для видео копии кадров уменьшены до 1920 пикселей без изменения композиции. Монтаж экранных состояний не является замером скорости обработки.
