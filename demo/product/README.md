# Продуктовая демка FaceFlow

[Смотреть или скачать MP4](faceflow-demo.mp4) · [Субтитры](subtitles.srt) · [Авторы и лицензии](credits.md)

50 секунд, 1920×1080/24 fps, без звука. Настоящий интерфейс и реальные кадры Wikimania 2019. Ролик показывает загрузку съёмки, поиск по селфи, просмотр и скачивание выбранных фотографий. [Описание и границы](../../docs/DEMO.md).
