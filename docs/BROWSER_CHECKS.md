# Программная проверка интерфейса

Windows, Python 3.12 с зависимостями проекта и проверенными моделями. Из корня репозитория:

```powershell
npm ci --ignore-scripts
npm run browser:install
npm run test:browser
```

Повторный запуск - одна команда `npm run test:browser`. Другой каталог результатов:

```powershell
npm run test:browser -- --output work/browser-check
```

Playwright 1.62.1 закреплён в package-lock.json. Установщик скачивает отдельный Chrome for Testing 153.0.8010.36 из официального хранилища Google, проверяет SHA-256 архива и распаковывает его в игнорируемый `work/test-browser`. Этот браузер нужен только тесту, не приложению. Пользовательский браузер, его профиль и системные настройки не меняются. `FACEFLOW_BROWSER_EXECUTABLE` допускает явно выбранную копию той же версии, `FACEFLOW_PYTHON` - другой Python с зависимостями проекта. Чужая node_modules не используется.

Тест создаёт отдельные базу, HTTP-сервер и профиль браузера. Через действующий интерфейс создаёт съёмку, загружает два существующих синтетических исходника, публикует её и выполняет поиск. Это настоящие Flask/Waitress/OpenCV, а не подставленные API-ответы. Точность распознавания на людях не оценивается.

Пять режимов: desktop 1280×800, тот же viewport с настоящим browser zoom 200%, reduced motion, 390×844 и 320×700. Для масштаба маленькое тестовое расширение в отдельном профиле вызывает [chrome.tabs.setZoom](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-setZoom). Проверяются getZoom=2, уменьшившийся CSS viewport и увеличившийся devicePixelRatio при visualViewport.scale=1. CSS zoom и pinch zoom не используются. [Запуск расширения в отдельном headless Chromium](https://playwright.dev/docs/chrome-extensions).

Для reduced motion используется штатный [page.emulateMedia](https://playwright.dev/docs/emulation#color-scheme-and-media). Тест читает настоящий matchMedia, наблюдает изменения стиля результатов/viewer, проверяет отсутствие активных GSAP tweens и итоговые opacity/transform. При обычном режиме должен наблюдаться переход; при reduce - неподвижный интерфейс. MutationObserver только записывает изменения, не заменяет matchMedia, стили или функции продукта.

Дополнительно проверяются загруженные превью и их размеры, отсутствие горизонтального переполнения, попадание центра основных действий в собственную кнопку, выбор, световой стол, Tab/Shift+Tab внутри диалога, Escape и видимый фокус возвращённого кадра, настоящее скачивание ZIP. Снимки текущего viewport через Page.captureScreenshot без clip (без склейки полной страницы и ошибки CSS-координат при browser zoom) и JSON находятся в `work/browser-check`. Проверка не является полным WCAG-аудитом, тестом экранного диктора или физического телефона. Она не сравнивает пиксели с эталоном: геометрия и действия проверяются утверждениями, снимки предназначены для визуального review.

Сервер и браузер закрываются в finally. При успехе временные профиль/база удаляются; при ошибке остаются в отдельном `work/browser-run-*` для диагностики. Ключи не включаются в отчёт. Скриншот фотографа делается до публикации гостевой ссылки. CI запускает ту же команду после интеграционных тестов, без автоматической публикации артефактов.
