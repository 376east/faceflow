# Интерфейс FaceFlow

Рабочий кабинет фотографа и личная подборка гостя. Визуальное направление - спокойный цифровой фотоальбом: тёплая бумага, тёмные чернила, настоящие обложки съёмок и цельные фотографии. Объекты в галерее не обрезаются; административная обложка использует object-fit: cover. [CSS](../web/style.css), [клиент](../web/app.js).

Manrope используется в контролах и тексте, Literata - только в заголовках альбома и подборки. Кириллица и латиница размещены локально; font-display: swap сохраняет читаемость при загрузке. Основная кнопка тёмная, вторичные действия спокойные; красная рамка найденного лица сохранена. [Шрифты и лицензии](../web/vendor/).

В кабинете используются четыре показателя: всего фото, готово к просмотру, поиски и скачивания. Обложки приходят одним запросом со списком съёмок, только с административным доступом. На телефоне есть быстрый переход к форме новой съёмки. Подборка резервирует место для изображений по ширине и высоте из поиска; ключ гостя сохраняется при переходе к содержимому. [API](API.md), [проверки](../tests/test_flow.py).

## Сборка и доступность

Для обновления локальных ассетов: npm ci, затем npm run vendor. Версии фиксируют package.json/package-lock.json; vendor-файлы включены в репозиторий, обычный запуск Flask не требует Node.js. [Скрипт](../scripts/vendor-ui.cjs).

Сохраняются стандартные input, checkbox и dialog, Escape, стрелки просмотра и видимый фокус. Нет анимаций при загрузке страницы, перехвата прокрутки, эффектов наведения на сенсорных экранах или внешних сетевых запросов шрифтов. [Движение](../web/motion.js), [проверки](../tests/test_motion.cjs).

Записанный ролик 14 октября остаётся самостоятельным предыдущим артефактом; текущие изменения относятся к рабочему продукту.


## Перенос прототипа в рабочую галерею

Фотоархив сохраняет настоящий поиск по селфи, согласие, красную рамку найденного лица, подписанные ссылки и серверный ZIP. В найденной подборке доступны фильтр по номеру кадра, только выбранные и световой стол. Фильтр скрывает кадры, сохраняя выбор; «Выбрать все» действует на видимые доступные кадры. ZIP по-прежнему содержит весь выбор, включая скрытые фильтром кадры. [Клиент](../web/app.js), [управление галереей](../web/gallery-controls.js), [регрессии](../tests/test_gallery.cjs).

GSAP 3.15.0/Flip перестраивает одни и те же кадры между альбомом и световым столом за 240 мс, отключаясь при reduced motion. PhotoSwipe 5.4.4 (MIT) увеличивает оригинал с масштабированием и перетаскиванием; закрытие возвращает в обычный просмотр с рамкой/выбором/обратной связью. При истечении ссылки оба просмотра закрываются. Локальные UMD/CSS и уведомление PhotoSwipe восстанавливаются npm ci + npm run vendor. [Точные версии](../package.json), [vendor](../scripts/vendor-ui.cjs), [компонент](../web/gallery-controls.js).

Lenis и клиентский fflate не перенесены: обычная прокрутка и существующий серверный ZIP сохранены. Прототипный Radix не заменяет штатный dialog. Данные и распознавание не подменены демонстрацией; новый режим не является оценкой качества поиска.

## Отбор и восстановление поиска

«Снять весь выбор» очищает также скрытые фильтром кадры и обновляет серверную ZIP-ссылку; после истечения доступа действие недоступно. Ошибки селфи, размера файла, ограничения запросов и соединения объясняют следующий шаг. При повторе поиска выбранное селфи остаётся в форме. На широком экране подборка использует больше места; подписи фотографий и действий увеличены. [Клиент](../web/app.js), [отбор](../web/gallery-controls.js), [регрессии](../tests/test_search.cjs).
