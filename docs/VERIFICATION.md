# Проверка публичного экспорта

Проверено 4 октября 2026 на Windows, Python 3.12.14. Поля и хеш готового видео находятся в [verification.json](verification.json). Это проверка функциональной цепочки на двух синтетических исходниках, не отчет о точности для мероприятий.

- Установка в новое виртуальное окружение по requirements.txt прошла. download_models.py скачал обе закрепленные модели; размеры и SHA-256 совпали с manifest.json.
- Восемь интеграционных тестов прошли с настоящим OpenCV inference. Они покрывают поиск, различение двух исходников, отсутствие и несколько лиц, ограничения доступа и consent, выбор ZIP, отзыв ссылки, повтор индексации, восстановление удаления и конкурентное удаление. [tests/test_flow.py](../tests/test_flow.py).
- В браузере гостевой сценарий вернул два варианта A; выбор одного кадра дал исправный ZIP с одним JPEG. Ошибок консоли в проверенной вкладке не было.
- seed_demo.py и запуск Waitress на 127.0.0.1:8766 проверены в отдельном хранилище. Пользовательские данные исходного локального проекта не использовались.
- JavaScript прошел node --check; Python прошел compileall.
- Установлен optional requirements-demo.txt; voice_demo.py действительно выполнен через Microsoft Svetlana, затем render_demo.py пересобрал MP4. Все фразы помещаются в свои сцены; входы озвучки не содержат ё.
- MP4 1920×1080, 60 fps полностью декодируется FFmpeg без ошибок. Ключевые кадры просмотрены. В ролике и сохраненных снимках только вымышленные персонажи и локальный интерфейс.
- Публикуемый набор проверен на известные живые ключи, пути пользовательского ПК, старый контекст, запрещенные хранилища и битые относительные ссылки. Экспорт начинает новую Git-историю.

Не проверены: независимая точность и удобство для реальных пользователей, все браузеры, Linux-запуск, нагрузка на больших съемках, безопасность публичного хостинга. Локальное приложение не развернуто в интернет. Полная проверка лицензий зависимостей и выбор лицензии собственного кода не заменяются этим техническим прогоном. [PLAN.md](../PLAN.md), [THIRD_PARTY.md](../THIRD_PARTY.md).
