# Проверка сложной демосъёмки

## Что взято из бенчмарков

Для поиска в галерее подходит протокол 1:N: проверочное изображение ищется среди многих участников. NIST отдельно считает пропуски нужного человека и ложные выдачи для людей, которых в галерее нет. Наш сценарий возвращает все фотографии человека, поэтому дополнительно считаем верные/лишние/пропущенные фотографии и precision/recall. Это адаптация принципа, не участие в NIST и не сопоставимый с ним результат. [FRTE 1:N](https://pages.nist.gov/frvt/html/frvt1N.html).

VGGFace2 покрывает изменения позы, возраста и освещения, содержит много разных изображений каждого человека и разделяет train/test по идентичностям. Для демосъёмки важны разные ракурсы и свет, а не варианты яркости одного файла. [Описание VGGFace2](https://github.com/ox-vgg/vgg_face2/blob/master/README.md).

## Выбор данных

DigiFace-1M содержит большой синтетический набор, но его соглашение ограничивает использование некоммерческим исследованием и запрещает включать данные или результаты в коммерческое предложение. SCface также запрещает коммерческое использование и имеет ограничения на распространение изображений. Эти наборы не скачивались и не включались в продуктовую демку. [DigiFace: LICENSE](https://github.com/microsoft/DigiFace1M/blob/main/LICENSE), [SCface: release agreement](https://scface.org/SCface_release_agreement.pdf).

PIPA ближе к задаче: целые фотографии из альбомов, повторяющиеся люди, head bounding boxes и identity. Однако исходный архив больше не доступен по старой ссылке; авторский репозиторий содержит разметку и предлагает восстановление снимков через Flickr. Прямое открытие Flickr в этой проверке не удалось. Доступность всех исходников и условия их повторного использования не подтверждены. [Авторский репозиторий PIPA](https://github.com/coallaoh/PIPA_dataset), [статья](https://arxiv.org/abs/1501.05703).

Для следующего локального демо выбраны полные репортажные фотографии Wikimania 2019 с Wikimedia Commons. Это обычные групповые сцены, рабочие столы, зал и общение. Проверяются лицензия каждого файла, автор, исходная ссылка и SHA-256. Крупные одиночные портреты и повторные кропы исключаются. Детектор помогает отобрать сцены с несколькими лицами, но окончательный выбор требует просмотра: число найденных лиц не гарантирует нужную композицию. [Фото мероприятия](https://commons.wikimedia.org/wiki/Category:Wikimania_2019), [Hackathon](https://commons.wikimedia.org/wiki/Category:Wikimania_2019_Hackathon).

Commons-альбом не является готовым identity-бенчмарком: у него нет полной разметки присутствия людей. Предложения модели для повторяющихся лиц нельзя использовать как ground truth. Проверочные фото берутся из отдельных кадров, которые исключаются из галереи; такие кропы обозначаются как фото участника, а не настоящие независимо снятые селфи. Полные precision/recall допустимы только после ручной разметки всех проверяемых пар «человек - фотография».

Реальные фотографии, кропы, векторы лиц и локальные базы остаются вне Git согласно AGENTS.md. В репозитории сохраняется прежний синтетический набор, а `--dataset PATH` позволяет проверить внешний манифест v2 без копирования изображений в fixtures. Внешний манифест должен явно задавать `description`, чтобы реальный альбом не получил синтетическое описание по умолчанию.

## Протокол

1. Зафиксировать состав альбома и метки участников до итогового прогона.
2. Загрузить весь альбом через обычный API, дождаться обработки и публикации.
3. Выполнить поиск по всем селфи при штатном пороге 0.60.
4. Сопоставить фактически возвращённые имена фото с манифестом. Считать TP/FP/FN, precision и recall для участников; для людей вне галереи - пустые и ложные выдачи.
5. Отдельно показать результаты по типам сцены и сложности; сохранить задержки API и проверить все JPEG/ZIP.
6. В ролике показывать настоящие ответы интерфейса. Ошибки не вырезать из отчёта и не менять порог ради красивых цифр.

Предыдущие синтетические наборы использовали референсы персонажей для новых кадров. Их результаты являются контролируемой демонстрацией, а не независимой оценкой качества на реальных людях. Размер новой локальной подборки также не позволяет заявлять демографическую точность.

Сохранённый в репозитории [assessment.json](../demo/assessment.json) относится к прежнему синтетическому набору из четырёх персонажей. Его нельзя выдавать за результаты на Commons. Отчёт внешнего набора задаётся через `--report PATH` и хранится локально. Если хотя бы одна выдача расходится с заранее установленными метками, checker сохраняет отчёт и завершается с кодом 1.

## Локальная проверка 14 октября 2026

Отобрано 86 общих фотографий. В обычном приложении после включения `detailed`: 86 ready, pending 0, errors 0, 1347 обнаружений лиц, включая повторные появления людей. Десять сложных кадров взяты в исходном разрешении, остальные - в 1600-pixel версии Commons. Четыре проверочных фото лица вырезаны из отдельных снимков, которых нет в галерее. [Локальный протокол](../../work/hard-event-demo/commons/search-audit.json), [источники и лицензии](../../outputs/faceflow-real-event-credits.md).

Четыре запроса трёх людей вернули 3, 3, 3 и 0 фотографий; второй и третий запросы относятся к одному человеку с разных ракурсов. Все возвращённые JPEG и ZIP проверены. На вручную подтверждённом подмножестве одного человека найдено 3 из 4 кадров, ещё один сложный запрос не нашёл 3 подтверждённых кадра. Полная разметка всех пар «человек - фотография» отсутствует, поэтому общие precision/recall и точность на независимых селфи остаются UNKNOWN. Контрольное синтетическое лицо вне реального альбома вернуло пустую выдачу; групповое фото на входе отклонено с 400. [Локальный протокол](../../work/hard-event-demo/commons/search-audit.json).

Отдельно обнаружен и исправлен отказ детектора на крупном плане лица: если на большой картинке нет кандидатов, детекция повторяется в масштабе до 640 пикселей. Регрессионный тест с синтетическим крупным селфи сначала получил 400, затем 200 и одно совпадение; пустое изображение по-прежнему отклоняется. Все 12 Python-тестов прошли. Порог сходства 0.60 и модели не менялись. Проверка прежних 96 синтетических фото сохранила TP 101 / FP 0 / FN 4; код 1 отражает прежние пропуски, а не новую регрессию. [Код](../recognition.py), [тест](../tests/test_flow.py), [локальный протокол синтетической проверки](../../work/hard-event-demo/synthetic-regression-large.json).
