# Демо на одной синтетической съёмке

[Ролик](../demo/faceflow-demo.mp4): 80 секунд, 1920×1080, 24 fps, встроенные русские субтитры, без звука. Показывает создание съёмки, загрузку альбома, поиск по двум селфи, просмотр кадров и скачивание выбранной подборки. Это монтаж настоящих состояний интерфейса, не непрерывная запись и не замер скорости. [Исходник](../demo/index.html), [субтитры SRT](../demo/subtitles.srt).

В альбоме 96 самостоятельных фотографий одного вымышленного мероприятия. Четыре повторяющихся взрослых персонажа сняты с разными позами, ракурсами и светом; есть парные кадры. Отдельные четыре портрета используются как селфи и не входят в альбом. [Манифест с составом кадров](../demo/synthetic/event-manifest.json), [происхождение](../demo/synthetic/PROVENANCE.md).

## Проверка

Обычный API при неизменном пороге 0.60 обработал 96/96 фото без ошибок. Для четырёх селфи: Aya - 28 верных совпадений, Arjun - 25, Mei - 24, Max - 24. Лишних совпадений нет; у каждого персонажа пропущено по одному появлению в сложном парном кадре. Всего 101 верное совпадение и 4 пропуска. Проверены все возвращённые JPEG и четыре ZIP. Выбранный в браузере ZIP содержит три исправных фотографии. Это результат на данном синтетическом наборе, не оценка точности на настоящих мероприятиях. [Полный отчёт](../demo/assessment.json), [проверка API](../scripts/check_demo.py).

## Запуск

Из корня репозитория в окружении из README:

```powershell
python scripts/download_models.py
python scripts/seed_demo.py --timeout 600
$env:FACEFLOW_DATA = './work/demo-data'
python app.py --port 8766
```

Сидер всегда использует `work/demo-data` и при каждом запуске добавляет новую съёмку. Ссылки фотографа и гостя находятся только в исключённом из Git `work/demo-session.json`. Для пустого альбома перед ручной загрузкой: `python scripts/seed_demo.py --empty`. После остановки сервера убери переменную: `Remove-Item Env:FACEFLOW_DATA`. [Скрипт](../scripts/seed_demo.py).

Для проверки набора: `python scripts/check_demo.py --timeout 600`. Отчёт записывается в `work/demo-assessment.json`. Код выхода 1 означает несовпадение с манифестом, включая перечисленные четыре пропуска; ошибки API прекращают проверку. Подборка в видео берётся из настоящего поиска, манифест её не подменяет.

## Пересборка

Нужны Node.js 22+, npx и FFmpeg. Используется закреплённый HyperFrames 0.8.153:

```powershell
python scripts/render_demo.py --preview
python scripts/render_demo.py
```

Перед сборкой выполняется проверка композиции. Пробные кадры идут в `work/demo-preview`, видео - в `demo/faceflow-demo.mp4`. Поиск и модели для пересборки сохранённых экранов не нужны. GSAP сохранён локально; генерация фото и TTS при пересборке не вызываются. [Скрипт](../scripts/render_demo.py).

Новые экраны снимай во встроенном браузере из отдельной синтетической сессии. Не сохраняй адресную строку, ключи в блоке публикации и пользовательские материалы. `demo/narration` и `demo/scenes.json` относятся к прежнему ролику и в текущем монтаже не используются.
