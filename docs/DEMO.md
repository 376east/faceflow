# Как собрана демка

[Готовый ролик](../demo/faceflow-demo.mp4) показывает текущий гостевой интерфейс и настоящий поиск YuNet/SFace. Это монтаж состояний браузера, а не непрерывная запись и не замер скорости. В ролике нет настоящих людей, пользовательских баз, исходных селфи или ключей. Все входы лежат в [demo](../demo).

## Что именно проверяется

Галерея содержит четыре изображения: два варианта одного синтетического портрета A, портрет B и изображение без лица. Поиск исходным портретом A возвращает два варианта A. Выбор одного кадра дает ZIP с одним файлом. Два варианта A созданы из одного источника, поэтому результат подтверждает функциональный сценарий, но не узнавание человека на независимых съемках. Источники: [seed_demo.py](../scripts/seed_demo.py), [интеграционные тесты](../tests/test_flow.py).

## Подготовить отдельную съемку

В активированном окружении из README:

```powershell
python scripts/download_models.py
python scripts/seed_demo.py
$env:FACEFLOW_DATA = './work/demo-data'
python app.py --port 8766 --open
```

`seed_demo.py` всегда использует `work/demo-data`, даже если в оболочке уже задан другой `FACEFLOW_DATA`. Он добавляет новую съемку при каждом запуске. Ссылки фотографа и гостя сохраняются только в локальный `work/demo-session.json`; этот файл исключен из Git. Для обычного запуска после демо убери переменную: `Remove-Item Env:FACEFLOW_DATA`. Источник: [скрипт](../scripts/seed_demo.py).

## Пересобрать готовый ролик

Установи FFmpeg и проверь, что команда `ffmpeg -version` доступна. Веса моделей для монтажа не нужны. Кадры и одобренная озвучка уже находятся в репозитории:

```powershell
python scripts/render_demo.py --preview
python scripts/render_demo.py
```

При другом пути к FFmpeg: `python scripts/render_demo.py --ffmpeg 'C:/path/to/ffmpeg.exe'`. При отсутствии системного шрифта: `--font '/path/to/regular.ttf' --bold-font '/path/to/bold.ttf'`. По умолчанию используются Segoe UI на Windows или DejaVu Sans на Linux. Файлы шрифтов не распространяются в репозитории. Скрипт создает `demo/faceflow-demo.mp4` и `demo/poster.png`; промежуточные звуковые и пробные кадры идут в `work`. Источник: [render_demo.py](../scripts/render_demo.py).

Монтаж: Pillow для кадров, NumPy для оригинального электронного ритма, FFmpeg для H.264/AAC. Голос: Microsoft `ru-RU-SvetlanaNeural`, темп `+0%`. Все входные тексты озвучки используют `е` вместо `ё`. Готовые WAV сохранены, поэтому обычная пересборка не обращается к TTS-сервису. [Тексты и длительности](../demo/scenes.json), [WAV](../demo/narration).

Если нужно заново синтезировать голос, потребуется интернет и отдельная зависимость:

```powershell
python -m pip install -r requirements-demo.txt
python scripts/voice_demo.py
python scripts/render_demo.py
```

`voice_demo.py` обращается к сетевому TTS через edge-tts. Доступность стороннего сервиса не гарантирована. Он обновляет длительности сцен под полученные WAV, чтобы голос не выходил за свою сцену. Это инструмент производства демо; продукт FaceFlow его не вызывает. Источник: [voice_demo.py](../scripts/voice_demo.py).

## Обновить экраны после изменения UI

Этот этап ручной. Скрипт монтажа не открывает браузер и не нажимает кнопки.

1. Открой гостевую ссылку из `work/demo-session.json`. В режиме адаптивного экрана браузера установи 1440×900 CSS px, масштаб 100%.
2. Сохрани снимок страницы без браузерной адресной строки как `demo/frames/guest.png`. Используй полную страницу.
3. Добавь `demo/synthetic/person-a.png`, отметь согласие; сними полную страницу `portrait.png`.
4. Нажми «Найти мои кадры», дождись двух результатов; сними полную страницу `results.png`.
5. Открой первый кадр; сними только видимую область 1440×900 как `viewer.png`. Сохранение полной страницы с диалогом меняет его положение на снимке.
6. Закрой просмотр, выбери первый кадр; сними полную страницу `selected.png`. Скачай ZIP и проверь, что внутри один файл.
7. Убедись, что на снимках нет адресной строки, ссылок с ключами, реальных людей и пользовательских файлов. Пересобери ролик и просмотри его целиком. При изменении геометрии UI проверь `crop` в [scenes.json](../demo/scenes.json).

Для текущей записи использовался браузер Codex и ручные команды управления. Этот доступ не нужен для пересборки сохраненных кадров. Исходные изображения сгенерированы встроенным imagegen; точные запросы находятся в [описании данных](../demo/synthetic/PROVENANCE.md). Новая генерация не обязана воспроизводить те же лица, поэтому тесты и демо по умолчанию используют закрепленные PNG.
